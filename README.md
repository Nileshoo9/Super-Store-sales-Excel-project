# Super Store Sales Analysis — Excel Projects

This repository contains two Excel-based sales analysis workbooks using Superstore-style sales data. It presents an independently developed workbook alongside a separate AI-assisted workbook.

## Project 1 — Independently Developed Excel Project

**File:** `01-Self-Created-Excel-Project/Super store excel project.xlsx`

- Executive sales dashboard with 8 charts
- Supporting sales and dashboard-data worksheets
- Sales records covering 2015–2018
- Analysis across category, region, segment, shipping mode, month, and product

## Project 2 — AI-Assisted Excel Project

**File:** `02-AI-Assisted-Excel-Project/Super_Store_Sales_Dashboard.xlsx`

- Sales dashboard with 7 charts
- Dashboard filters for year, region, segment, and category
- Supporting calculation worksheet
- Sales dataset containing 9,800 records

**Development disclosure:** AI tools assisted with the development of the second workbook. The first workbook is presented separately as independently developed work.

## Dataset

The workbooks use Superstore-style transaction data from 2015–2018, with approximately 9,800 records. Fields cover orders, shipping, customers, geography, product categories, and sales.

## Tools and Skills

- Microsoft Excel
- Data analysis and data organization
- Dashboard design and KPI reporting
- Charts and data visualization
- Summary tables and supporting calculations
- Interactive dashboard filters

## How to Explore

1. Open a workbook in Microsoft Excel.
2. Start with the dashboard worksheet.
3. Use available filters and slicers where supported.
4. Review supporting worksheets for underlying data and calculations.
